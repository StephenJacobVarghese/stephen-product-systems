REFERENCE RESPONSIBILITY

Each input gets a job.

Instead of throwing every image at the model equally, the workflow assigns responsibility: storyboard for framing and screen direction, master image for spatial continuity, identity sheets for character consistency, and environment references for world stability.

Reference hierarchy is product logic—not prompt decoration.
