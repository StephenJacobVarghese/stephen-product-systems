# Stephen Varghese — AI Product Systems Portfolio

A static portfolio focused on product-facing creative technology, multimodal AI quality, and creator-tool workflows.

## Publish with GitHub Pages

1. Extract the ZIP file.
2. Upload **everything inside this folder** to the root of your GitHub repository.
3. Confirm that `index.html`, `styles.css`, `app.js`, and the `assets` folder appear together at the top level.
4. Commit the upload to the `main` branch.
5. Open **Settings → Pages** in the repository.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select **main** and **/(root)**, then click **Save**.

GitHub will show the public URL after the deployment finishes. No build command or framework is required.

## Local preview

Open `index.html` in a browser. For the most reliable video playback, serve the folder through any simple local web server.
